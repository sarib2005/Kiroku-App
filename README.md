# Kiroku-App

An anime, manga, manhwa, manhua and light novel tracker for Android. Built with React Native, Expo and Firebase.

> *Kiroku* (記録) means "record" in Japanese. Every episode, every chapter, on record.

Kiroku is one place to track everything you watch and read, so you never lose your place and never have to juggle five different lists.

Website: [kiroku-app.vercel.app](https://kiroku-app.vercel.app)

## Download

Get the latest APK from the [Releases](https://github.com/sarib2005/Kiroku-App/releases/tag/1.2) page.

1. Download the `.apk` file from the latest release.
2. Open it on your Android phone and allow installation from your browser or file manager if asked.
3. Install and open Kiroku.

The app checks for updates on its own and lets you know when a new version is ready.

## Features

**Track everything**
- Anime, manga, manhwa, manhua and light novels, all in one app
- Statuses for Watching/Reading, Wishlist, On Hold, Dropped and Completed
- Episode, chapter and volume progress, so you always know where you left off
- A library you can search, filter and group by franchise

**Discover what's next**
- Trending, airing, seasonal, top rated, popular and upcoming titles
- Search with genre, format and status filters
- Characters, voice actors, staff and related titles
- Official reading links for manga
- **Continue in Manga:** finished an anime season? Kiroku shows where to pick up the manga

**Rate and rank**
- Rate what you've completed and see the community average
- Build your own Top 10 lists for anime, manga and manhua
- Get gentle nudges about titles you've wishlisted, paused or dropped

**Share with friends**
- Public or private profiles
- Add friends, chat with them and send recommendations
- Climb the global and friends leaderboards

**Easy to start**
- Sign in with email, Google, AniList or MyAnimeList
- Import your existing list from AniList or MyAnimeList

## What Kiroku isn't

Kiroku is for tracking and discovery only. It has no built-in reader and no streaming.
